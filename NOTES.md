# Specification Notes

## Words area

3 visible lines, start from the 1st line

Scroll down when transitioning from 2nd to 3rd visible line, even if the 3rd line is the last line

Scroll up when transitioning from 2nd to 1st visible line and that line still has at least 1 line above it

The width of the words area should be half of the viewport width on a desktop 16:9 screen
